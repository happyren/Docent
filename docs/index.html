Docent

Install on macOS

Docent is open-source and unsigned — we don't pay Apple's yearly developer fee, so macOS flags browser downloads. That's a missing signature, not malware; the source is public if you'd like to check what you're running.

Recommended — one Terminal line, no security prompts

Terminal downloads skip macOS quarantine entirely, so the app opens like any other:

curl -fsSL -o /tmp/Docent.zip https://github.com/happyren/Docent/releases/latest/download/Docent_macos_universal_portable.zip && ditto -x -k /tmp/Docent.zip /Applications && open /Applications/Docent.app

Or download in the browser

Download the zip, unzip, then clear the quarantine flag once and open normally:

xattr -cr ~/Downloads/Docent.app

macOS will otherwise report the app as "damaged" — current macOS offers no Open Anyway for unsigned apps. One universal build covers Apple Silicon and Intel.

Install on Windows

Download for Windows (portable zip)

Unzip and run docent.exe — a single file, no installer. If SmartScreen appears: More info → Run anyway (same reason: no paid code-signing certificate).

Needs Microsoft's WebView2 runtime, preinstalled on Windows 11 and current Windows 10. Older machine? Use the NSIS installer from the release page — it fetches the runtime.

Install on Linux

Download for Linux (AppImage)

chmod +x Docent_amd64.AppImage && ./Docent_amd64.AppImage

.deb and .rpm packages are on the release page.

Self-host (Docker)

The same app as a shared team deployment — portfolio store and the MCP agent endpoint included:

git clone https://github.com/happyren/Docent.git && cd Docent && docker compose up

Serves on port 3000 (override with DOCENT_PORT). See the README for the continuous-deployment installer and agent control.

What it does

  • Longtake presentations — frames become waypoints; one continuous camera glide, no slide cuts.
  • Tiered drill-down — click a component, dive into its inner mechanism; unbounded layers on one canvas.
  • GitHub sync — bind a project to a repository: every save is a commit, drafts on branches, pull requests from the app.
  • Semantic export — deterministic Mermaid + compact JSON with provenance on every fact, built for AI readers.
  • Agent-drivable — an open MCP endpoint lets any AI agent move the camera, highlight components, and narrate tours (self-hosted deployments).
  • Project portfolio — projects of scenes with large previews, stored as plain .excalidraw files.
  • Visual review — every push carries a semantic changelog in the diagram's own words, and the app shows each changed frame before and after at the same rectangle.
  • Plugins — the desktop app hosts out-of-process providers behind versioned contracts; nothing runs inside the canvas.
  • Agents that draw — an agent adds components, edges, frames and detail layers in the diagram's own style, with intents and logic filled in; every edit is one undo step, shown under an orange frame, and reviewable.
  • Symbols — an agent that needs a Lambda finds it by name in the bundled AWS and software‑architecture libraries and places the icon as one component, labelled, with arrows that meet its border and follow it when it moves.
  • Pleasing by construction — what an agent draws is laid out the way a careful human would lay it out: no crossings, straight flows, gentle turns, room for every label, colours that mean something. Tidy (⌥⇧F) does the same to any diagram — and never changes what it says.
  • Five genres — architecture map, life of a request, event flow, data flow, lifecycle. Name one and its vocabulary, its layout posture and its own lint arrive with it.

The five genres new

Nearly every diagram a developer reaches for is one of five disciplines, and Docent knows all five. Ask for one — use_genre({genre}), or create_scene({genre}) at birth — and the choice is recorded beside the legend, where it exports and diffs like every other fact: the genre's vocabulary seeds the legend's kinds, the layout takes the genre's posture, and the lint starts speaking the genre's grammar. It advises and never refuses — an edit against the grain still lands, because the author may mean it.

Architecture map

C4-shaped: people, systems, services and stores, inside the boundaries that own them. Context, container and component are not three drawings to keep in step — they are tiers you dive through, on one canvas.

Life of a request

A scenario is a named, ordered path of edges over the map you already drew. flow pulses it, the guided tour walks it and speaks it, numbered step badges ride the overlay while it replays — so the diagram itself stays clean and one map carries as many stories as it has. The trace you debug with, not a second diagram to keep in sync.

Event flow

Commands, events and read models, a lane per context. Layout takes the lanes posture, so time runs left to right and stays left to right — no fold turns the timeline back on itself, and an event nothing commands is named out loud.

Data flow

Sources, transforms, stores, consumers — and the contract declared on the edge that carries it, not in a table somewhere else. The layout runs straight, because a time axis must not turn back on itself, and a cycle gets flagged where it closes.

Lifecycle

States and guarded transitions, with each guard written as logic on the arrow it guards. The lint asks about a state nothing reaches, and about a machine with no way to end.

UML class diagrams, ERDs, Wardley maps and classic flowcharts are deliberately not genres: data modelling belongs to a data modeller's tool, strategy maps are not debugging, and decision shapes with logic already cover a flowchart.

Diagrams that please new

An agent authors meaning; Docent draws. What the research on graph aesthetics ranks — fewest edge crossings first, fewest bends, straight and aligned flows, balance, room for every label — is what Docent's own layout engine optimises on every write: a proper layered pipeline (median sweeps with transpose, Brandes–Köpf coordinates), long flows that fold into bands instead of one endless row, edges that leave at spread ports and route around components with softened turns, and a legend whose colours are chosen for meaning and distinctness — danger is red, storage is blue, and every new kind stands as far from the others as the palette allows.

  • Tidy — the formatter for diagrams. One keystroke (⌥⇧F), the menu, or tidy({frame}) over MCP re-lays out a frame, a tier, or the whole diagram. It is guaranteed to change nothing but the picture: its semantic changelog is empty, by test.
  • The craft score — validate() answers with a score out of 100 and its parts (crossings, bends, alignment, overlaps, lengths, angles, colour), per frame, with one line of advice each — so an agent draws, validates, and tidies in a loop, and can say how good the picture is.
  • Deterministic — the same diagram tidies to the same picture on every machine; no force-directed randomness, no dependencies, no engine to install.

Plugins new

Extend the desktop app without touching it: a plugin is a folder with a manifest and a program Docent starts, stops, and proxies on its own loopback origin. Plugin code never runs in the page, so the canvas stays exactly as fast and as safe as it is. Anyone can build one against the documented contracts, in any language.

🔊 docent-pocket-tts — spoken narration
Every narration an agent gives, every tour step, and your own frame narratives during a presentation — spoken aloud by Kyutai's Pocket TTS, a 100M-parameter voice that runs on two CPU cores on your machine. No account, no key, nothing leaves the laptop. The tour waits for the voice.
Get the plugin

Requires the desktop app and uv. Install: clone, run install.sh, then View → Plugins… in Docent.
